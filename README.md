> 🧠 **Aion 2 Combat Analytics** is a lightweight, non-invasive overlay for Aion 2. It analyzes local network traffic to calculate damage and healing output, helping you optimize your rotation. **No memory reads. No DLL injection. No game file modification.**



## 🧭 WHAT IS THIS TOOL

Aion 2 is a fast-paced MMORPG where knowing your damage output is critical for clearing content [citation:1]. This tool provides a real-time overlay that tracks your performance and your party's performance.

**It is a local analytics tool.** It does not play the game for you, it does not reveal enemies through walls, and it does not automate your skills. It simply reads the combat data that the game already sends to your client and visualizes it.

> ⚠️ **IMPORTANT**: NCSOFT has a strict policy against tools that modify memory or automate gameplay. This tool is **packet-sniffing only** [citation:2][citation:6]. It does not read or write to game memory. However, use it at your own risk. The developers are not responsible for any account actions.

## 🚀 QUICK START

### Step 1 Download and Install

1.  **Download** the latest release from the button above.
2.  **Extract** the archive to any folder.
3.  **Run** `Aion2Analytics.exe` as Administrator (required for packet capture).

### Step 2 Configure

1.  Select your **server region** (KR, TW, or Global).
2.  Choose your **network adapter** (if you use a VPN, select the VPN adapter).
3.  Click **Start Analysis**.

### Step 3 Play

1.  Launch Aion 2 normally.
2.  Enter a dungeon or raid.
3.  The overlay will automatically appear and start tracking combat.

## ❓ FAQ

### ❓ Is this a cheat?
**No.** It does not modify the game client, it does not inject code, and it does not automate gameplay. It only reads the network traffic that the game already sends to your computer [citation:2].

### ❓ Will I get banned?
NCSOFT has a strict policy against tools that modify memory or automate gameplay. Because this tool only reads packets, it is generally considered safer than memory-based tools. However, **use it at your own risk**. The developers are not responsible for any account actions.

### ❓ Does it work on the Global server?
**Yes.** It supports KR, TW, and Global servers. Make sure to select the correct region in the settings.

### ❓ Why does it need Administrator rights?
Packet capture on Windows requires elevated privileges. This is a standard requirement for any network analysis tool [citation:6].

### ❓ Can I use it in PvP?
**No.** The tool is designed for PvE combat analysis. Using it in PvP may violate the game's terms of service and could attract unwanted attention.
